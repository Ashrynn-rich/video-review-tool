# 🎬 影片審核工具

在瀏覽器裡就能使用的**影片逐幀評論工具**。像 Word 對文字加註解一樣，在影片的某一幀上留下評論、畫圖標註，再把評論交給對方修改。

**👉 線上使用：https://ashrynn-rich.github.io/video-review-tool/**

---

## ✨ 功能特色

- **逐幀評論**：在影片暫停的那一幀留下意見，進度條上會出現標記點，點評論就能跳到那一幀。
- **評論區不擋畫面**：影片在左、評論在右（手機直向時，影片在上、評論在下）。
- **精準逐幀控制**：鍵盤 ← → 前後 1 幀（Shift + ← → 一次 10 幀），同時顯示幀號與時間碼。支援 30、60、90、120 fps。
- **畫圖標註**：畫筆、箭頭、圓圈、方框、橡皮擦；顏色與粗細可自選（背景不好認就換色）。
- **評論狀態**：🔴 待處理 → 🟡 已修改 → 🟢 已確認，或標為 ⚪ 不處理；可按狀態篩選，也可以回覆。
- **多人來回審稿**：審核者把評論存成小檔案交給剪輯者，剪輯者載入後就能看到每一則評論與畫的圖，修完再改狀態發回去。
- **匯出 PDF**：A4 橫向，一頁一則評論（畫面、評論、回覆、附件），給不使用工具的人看。
- **支援 iPhone / Mac / Windows**，手機與電腦都能用。

## 🔒 隱私說明

- **你的影片、評論、畫的圖、附件，全部只在你自己的裝置上處理，不會上傳到任何地方。**
- 這個工具沒有伺服器、不需要登入、沒有統計追蹤，也不會載入任何外部程式。
- 評論檔是你自己下載、再自己傳給對方（例如用通訊軟體），不經過本網站。

## 🚀 開始使用

### 電腦（Mac / Windows）
1. 用 **Safari、Chrome 或 Edge** 開啟上方的線上連結。
2. 按「📂 選影片」，選擇你的影片（MP4、MOV、M4V）。

### iPhone / iPad
1. 用 **Safari** 開啟上方的線上連結（可以「加入主畫面」方便下次使用）。
2. 按「📂 選影片」，從「照片」或「檔案」選擇影片。

> ⚠️ **請用連結開啟，不要把 HTML 檔下載到手機再點開**。iPhone 不會執行本機的 HTML 檔案，按鈕會全部沒有反應。

首次使用會請你輸入名字，評論會標上這個名字（只有自己的評論可以編輯、刪除）。

---

## 📖 操作步驟

### 一、審核者：留下評論
1. 按「📂 選影片」載入影片。工具會自動偵測幀率，也可以在右下的下拉選單手動改成 30／60／90／120 fps。
2. 找到要評論的畫面：
   - 播放／暫停：空白鍵，或按 ▶。
   - 逐幀：鍵盤 ← →，或畫面上的 ◀1、1▶、⏮10、10⏭（手機按住按鈕可連續跳）。
   - 也可以直接點、拖曳進度條。
3. 暫停後，在右邊輸入評論，按「新增評論」。
4. **想在畫面上圈出位置**：
   - 在評論輸入區按「✏️ 畫圖標註」，右側會變成畫圖面板。
   - ① 選圖形（畫筆、箭頭、圓圈、方框、橡皮擦）→ ② 選顏色 → ③ 選粗細。
   - 在影片上按住拖曳就能畫。畫錯了按「↩ 復原」。
   - 畫完直接在下方寫評論並按「新增評論」，送出後會自動離開畫圖模式。
   - 想不送出就離開：按影片下方的「✔ 離開畫圖」，或鍵盤 Esc。
5. 評論也可以「📎 附圖」，附上參考圖片。
6. 審完後把評論交給對方：
   - **📤 分享**（手機建議）：跳出系統分享選單，直接傳給對方。如果瀏覽器不支援，會自動改成下載。
   - **💾 儲存評論檔**：下載一個很小的 `影片名_審核.json`，再自己傳給對方。**影片不需要再傳**。

### 二、剪輯者：收到評論後
1. 打開工具，按「📂 選影片」選擇**同一支影片**，再按「📥 載入評論檔」選擇收到的 json。
2. 進度條上的色點就是評論位置。點色點或右邊的評論，影片會跳到那一幀，並顯示審核者畫的圖。
3. 修改完成後，把評論的狀態改成「🟡 已修改」，需要說明就按「💬 回覆」，最後再「💾 儲存評論檔」或「📤 分享」發回去。
4. 審核者確認後改成「🟢 已確認」。

### 三、一幀只能有一則評論
- 走到有評論的那一幀，右邊會自動捲到該則評論，影片上也會顯示它畫的圖。
- 該幀已有評論時，輸入區會改成「此幀已有評論」，並提供「回覆」與「編輯」（只有作者可以編輯）。補充意見請用回覆。

### 四、匯出 PDF
按「📄 匯出 PDF」，會產生 A4 橫向的 PDF，一頁一則評論：左上是那一幀畫面（含畫的圖），右邊是評論與回覆，附件放在畫面下方。附件較多時會自動接續頁。

## ❓ 常見問題

**iPhone 上按鈕都沒反應？**
你可能是把 HTML 檔存到手機再點開的。請改用線上連結，在 Safari 開啟。

**iPhone 拍的 MOV 影片可以用嗎？**
可以。iPhone 與 Mac 的 Safari 都能直接播放 iPhone 的 MOV（HEVC 編碼）。如果在 **Windows 的 Chrome／Edge** 播不出來，請改用 Safari，或先把影片轉成 MP4（H.264）。

**幀率偵測不準？**
工具會自動偵測，但瀏覽器沒辦法 100% 確定。如果逐幀位置不對，請在下拉選單手動改成影片實際的幀率。目前選項為 30／60／90／120 fps。

**載入評論檔時出現黃色警告？**
表示這份評論檔對應的影片，和你現在載入的影片檔名、長度或大小不一致，可能是不同版本。評論位置可能對不上，請確認是不是同一支影片。影片重新剪輯過的話，舊評論的位置可能偏移。

**手機上收到評論檔，要怎麼載入？**
先把檔案「儲存到檔案」，再回到工具按「📥 載入評論檔」選取。不能直接在聊天視窗點開。

**我的評論不見了？**
評論只存在你的裝置和你下載的評論檔裡，關閉網頁前請務必「💾 儲存評論檔」或「📤 分享」。網頁關閉時如果有未儲存的內容，瀏覽器會提醒你。

## ⚠️ 已知限制

- 只有 30、60、90、120 fps 四種幀率選項；24、25 fps 的影片會被當成 30 fps，位置可能有誤差。
- PDF 內的文字是圖片，不能選取複製。
- 90、120 fps 影片能不能順暢播放，取決於你的裝置與瀏覽器；逐幀切換不受影響。
- 瀏覽器無法呼叫電腦上的其他程式，所以工具只處理影片、評論與圖片。

## 💻 離線使用（僅限電腦）

下載本倉庫的 `index.html`，在 Mac 或 Windows 上用瀏覽器開啟即可，不需要網路。iPhone 不支援這種方式，請使用線上連結。
